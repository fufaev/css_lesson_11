* **Студент:** Корзун Анастасия, группа ППОИС-2609
* **Заявленный уровень:** PRO
* **Выбранная тема дизайна:** `theme-dvizh` (светлая палитра студии танцев «ДВИЖ» из командного макета Figma: `Primary #2D4BD6`, `Secondary #FFA800`, `Neutral/Dark #111111`, `Neutral/Light #FFFFFF`, гарнитура Montserrat)

Работа выполнена на основе группового Figma-макета лендинга танцевальной студии «ДВИЖ» (практическая работа по Figma, команда `Korzun_team`): цветовые токены, типографика, скругления и контент секций перенесены из командной дизайн-системы.

## Индивидуальные константы (`:root`)

* Фамилия `Корзун` (N = 6): `--card-min-width: 270px;` (`6 * 10 + 210px`)
* Имя `Анастасия` (M = 9): `--split-sidebar-width: 388px;` (`9 * 12 + 280px`)

## Реализованные требования уровня PRO

* **BASE:** шапка на Flexbox с `margin-left: auto` у CTA-кнопки; витрина педагогов на `repeat(auto-fit, minmax(min(100%, var(--card-min-width)), 1fr))` с вертикальным Flexbox внутри карточек и `aspect-ratio: 3 / 4` у фото; асимметричный сплит-блок контактов (`388px + 1fr`), перестраивающийся в одну колонку на экранах `< 768px`.
* **JUNIOR:** многослойный Hero (фото → затемнение → контент) через наложение слоёв в одной ячейке `grid-area: 1 / 1` без `position: absolute`; несимметричная Bento-сетка преимуществ с `.bento-card--wide` и `.bento-card--tall` на экранах `>= 1024px`; сетки без фиксированных высот; 5 семантических коммитов в ветке `homework-11`.
* **PRO:** интерактивный выбор тарифа через `.plan-card:has(.plan-card__radio:checked)` с видимой стилизованной радиокнопкой (без скрытия через `position: absolute`, доступна с клавиатуры); FAQ на `<details>`/`<summary>`; выравнивание строк карточек тарифов через `grid-template-rows: subgrid` внутри `@supports`; адаптивная типографика `clamp()`; стресс-тест неделимым словом на 320px с `overflow-wrap: anywhere` и `min-width: 0`.

## Компонент для итогового Сайта-Портфолио

Для переноса в итоговый проект подготовлен модуль тарифов (`.pricing-grid` + `.plan-card`): выбор карточки на чистом CSS через `:has()` и `:checked` без JavaScript, выравнивание внутренних строк по общей сетке через `subgrid` с фолбэком на обычный грид внутри `@supports` и видимый `:focus-visible` для клавиатурной навигации. Модуль самодостаточен: достаточно перенести разметку секции и соответствующий блок стилей вместе с дизайн-токенами из `:root`.
