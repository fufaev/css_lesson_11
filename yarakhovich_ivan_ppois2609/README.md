# Практическая работа №11: Коммерческая витрина и Bento-сетка кейсов (CSS Grid + Flexbox)

Данная практическая работа предполагает верстку адаптивной страницы коммерческой витрины и портфолио студии на базе предоставленного шаблона без использования JavaScript. 

## Основные этапы выполнения

1. **GitHub Fork Workflow**: необходимо сделать fork репозитория `fufaev/css_lesson_11`, склонировать его локально, создать ветку `homework-11` и разместить все файлы строго внутри персональной папки по шаблону `Фамилия_Имя_Группа`.
2. **Антиплагиат и вариативность**: параметры дизайн-токенов в `:root` настраиваются индивидуально на основе длины фамилии ($N$) и имени ($M$) студента:
   - Минимальная ширина карточки: `320px`.
   - Ширина левой колонки контактов: `328px`.
   - Тема оформления (`<body>`): темная (`theme-gymby`).

## Уровни сложности

* **BASE (до 75 баллов)**: линейная шапка на Flexbox (`margin-left: auto`), секция команды/проектов на CSS Grid с вертикальным Flexbox внутри карточек и асимметричный сплит-блок контактов, перестраивающийся на мобильных устройствах.
* **JUNIOR (до 90 баллов)**: включает уровень BASE, запрещает использование абсолютного позиционирования и фиксированных высот для сеток, добавляет Hero-баннер с многослойным наложением через Grid и асимметричную Bento-сетку преимуществ (`>= 1024px`). Требуется от 4 до 5 семантических коммитов.
* **PRO (до 100 баллов)**: включает предыдущие уровни, реализует интерактивный выбор тарифа через `:has()` и FAQ через `<details>`/`<summary>`, использует `subgrid` для выравнивания строк и адаптивную типографику через `clamp()` с защитой от переполнения.

В конце файла `css/style.css` необходимо заполнить обязательный блок документации `/* Своими словами */` с ответами на технические вопросы по каждому уровню.

## Структура проекта

```text
Фамилия_Имя_Группа/

```
