## Описание

Адаптивная коммерческая страница фитнес-клуба GYMBY, разработанная на основе шаблона преподавателя и командного макета Figma.

## Используемые технологии

- HTML5 - семантическая структура страницы.
- CSS Grid - основные сетки, Hero, Bento, карточки и контакты.
- Flexbox - навигация и выравнивание содержимого карточек.
- CSS `:has()` - интерактивный выбор тарифа без JavaScript.
- CSS `subgrid` - выравнивание строк карточек тарифов.
- CSS `clamp()` - адаптивная типографика.
- HTML `<details>` и `<summary>` - FAQ без JavaScript.

## Индивидуальные параметры

- `--card-min-width: 250px` - (4 × 10) + 210px.
- `--split-sidebar-width: 328px` - (4 × 12) + 280px.
- Тема оформления: `theme-gymby`.

## Компонент для будущего портфолио

Адаптивная Bento-сетка преимуществ, реализованная на CSS Grid с использованием `grid-column: span 2` и `grid-row: span 2`.

## Особенности реализации

Страница реализована без JavaScript. Адаптивная вёрстка поддерживает мобильные и десктопные разрешения. Изображения хранятся локально в папке `images/`.

## Проверки

Предусмотрены проверки адаптивности, корректности CSS Grid и Flexbox, отсутствия горизонтального переполнения, работы выбора тарифов и FAQ. Скриншоты проверок размещаются в папке `screenshots/`.
