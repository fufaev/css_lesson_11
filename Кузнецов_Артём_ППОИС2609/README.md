## Компонент для итогового Сайта-Портфолио

Для переноса в итоговый проект портфолио подготовлен модуль адаптивной витрины карточек (`.showcase-grid` и `.profile-card`). Сетка построена на CSS Grid через `repeat(auto-fit, minmax(min(100%, var(--card-min-width)), 1fr))` с защитой от переполнения на `320px`, пропорцией медиаблока `aspect-ratio: 3 / 4` и внутренним вертикальным Flexbox для выравнивания кнопок действия по нижнему краю карточки.
